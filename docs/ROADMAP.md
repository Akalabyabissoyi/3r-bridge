# Roadmap and community plan

Things only people can do, with the repository ready for each:

| Goal | Status | How |
|---|---|---|
| Expert review of scores | Protocol ready | docs/EXPERT_REVIEW.md, `scripts/review_stats.py`, `reviews/template.csv` |
| Verify catalogue citations | Open | Maintainer check; report errors with the evidence issue template |
| Zenodo DOI | Ready | Enable the Zenodo-GitHub integration, publish a release, add the DOI to `CITATION.cff` and the README |
| Paper | Draft | `paper/paper.md` (JOSS format); add the evaluation from the expert-review round |
| Live demo | Ready | docs/DEPLOY.md |
| Endorsement and pilots | Open | Share with NC3Rs, your AWERB, Named Persons, FRAME, Animal-free Research UK; record feedback below |
| More models | Open | precision-cut lung slices, iPSC neurons, bioprinted tissues, xenopus tadpoles, planaria |
| More jurisdictions | Started | EU, US, OECD notes exist; add Canada, Australia, India, China, Switzerland |
